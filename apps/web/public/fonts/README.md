# Local fonts

DM Sans and Manrope are shipped locally; the browser makes no Google Fonts request.
Downloaded from the official Google Fonts repository on 2026-10-14:

- [DM Sans variable font](https://github.com/google/fonts/tree/main/ofl/dmsans), `DMSans[opsz,wght].ttf`.
- [Manrope variable font](https://github.com/google/fonts/tree/main/ofl/manrope), `Manrope[wght].ttf`.

Original SIL Open Font License texts are included as `DM-Sans-OFL.txt` and `Manrope-OFL.txt`.
